# Spring Core and Maven - Different Exercise Solutions

This folder solves each exercise separately. Each project uses a different implementation style so the work is easy to review exercise by exercise.

- Exercise 1: basic XML bean configuration
- Exercise 2: XML setter dependency injection
- Exercise 3: AOP execution-time logging with `@Around`
- Exercise 4: Maven project/dependency/plugin setup
- Exercise 5: central Spring IoC XML container configuration
- Exercise 6: annotation-based beans with component scanning
- Exercise 7: constructor injection plus setter injection
- Exercise 8: basic AOP with before/after-returning advice
- Exercise 9: Spring Boot REST API with JPA and H2
